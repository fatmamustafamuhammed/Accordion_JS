# Accordion FAQ Project

This project is a simple, interactive Accordion FAQ built with HTML, CSS, and JavaScript. It displays a list of frequently asked questions, each of which can be expanded or collapsed to show or hide the answer.

## Features
- Responsive design with modern UI
- Accordion functionality: click a question to expand/collapse the answer
- Smooth transitions and visual cues (+/- icons)
- Custom background and styling
- Font Awesome integration for icons

## How It Works
1. Each FAQ item is a `.content-container` with a `.question` and `.answer`.
2. Clicking a question toggles the visibility of its answer and changes the icon from `+` to `-`.
3. Only the clicked question expands; others remain collapsed.
